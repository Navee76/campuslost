#  CampusLost – Lost & Found Management System

CampusLost is a web application designed to help college students and staff report, search, and find lost belongings within the campus. It provides a centralized platform to share lost and found item information, making it easier to reconnect people with their belongings.

Key Features
- Report lost and found items.
- Search for missing belongings.
- View item details.
- Simple and user-friendly interface.
- Designed for college students and staff.

Objective
To make the campus lost and found process easier, faster, and more organized through a digital platform.
